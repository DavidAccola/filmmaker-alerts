# Franchise Follow Feature Spec

## Summary
Allow users to follow "franchises" (TMDB keywords representing film/TV universes) and get notified when new entries are released. Franchises live in the contributor system alongside people and companies.

## Notification Behavior

- **Movie notifications**: use `contributor.releaseNotificationPrefs` if set, else global prefs. Default when following: theatrical + streaming.
- **TV notifications**: use `contributor.tvNotificationPrefs` if set, else global default TV prefs. Default when following: **Series Premiere only** (not global default which has more enabled).
- **No auto-add to watchlist** — just notify, user adds manually.
- **Deduplication**: franchise notifications merge with person/company notifications on the same tmdbId via existing reasons system.
- **Pause**: supported via existing `notificationsSnoozed` on Contributor.

## TV Notification Granularity
- Series premiere = a brand new show in this franchise aired its first-ever episode
- Other types (Season Premieres, Finales, New Episodes, Specials) available but off by default
- High-volume warning shown when user enables any of those four for a franchise

## Where Franchises Appear in Search
- Blended into Movie tab results when `showInMovie = true`
- Blended into TV tab results when `showInTv = true`
- DCAMU (movies-only) does NOT appear in TV tab
- Following from either tab always covers both movies and TV
- Franchises surface near the top when the search query matches the franchise name

## Detail Screen Sections (in order)
1. Header: franchise poster (from top work), name, knownFor (top 2 work titles), entry count ("82 movies · 15 TV shows"), notification prefs chips
2. Upcoming (movies + TV shows with future release dates, sorted ascending)
3. Latest Releases (most recent entries by release date)
4. Biggest Hits (by popularity/vote)
5. All Works (chronological, movies + TV interleaved) with filter toggles: All / Movies / TV
6. External link → https://www.themoviedb.org/keyword/{id}

## Notification Prefs in Header
For `franchise` and `company` types, the header shows tappable chips:
- "Movie notifications: [Theatrical] [Streaming] ✏" → opens ReleasePreferencesDialog
- Franchise only: "TV notifications: [Series Premiere] ✏" → opens TvPreferencesDialog

## Company Notification Prefs (also in scope)
Companies get the same "Movie notifications" chip row in their detail header. `releaseNotificationPrefs` stored on Contributor (HiveField 18) applies to both company and franchise.
